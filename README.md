# Tom & Emma's Wedding Website

Wedding website for **Tom and Emma**, 17 August 2027 at **The Barns at Delbury Hall**.

## Publish
Upload the contents to the `main` branch, then set **Settings > Pages > Source** to **GitHub Actions**. The site will publish to `https://tom-ankers.github.io/wedding-website/en/`.

## Local development
`npm install --legacy-peer-deps` then `npm run dev`.
